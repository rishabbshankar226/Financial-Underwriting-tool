## Implemented patch scope

The modified files contain compatible bug fixes, regression tests, dependency
pin/pruning changes, and documentation. Current route names, request/response
field names and types, CLI commands, SQL schema, and calculation-version labels
remain unchanged. Invalid helper inputs now raise the established ValueError;
oversized write bodies consistently return 413. Replay identifies larger
discrepancies instead of expanding its financial tolerance with balance size.

The new ASGI budget deliberately runs before JSON buffering and store
dependencies. Allowed data is replayed as one original byte sequence to the
existing route parser. It uses the already installed Starlette types, adds no
package, and returns on disconnect without dispatching an incomplete request.

The remaining decimal defects are not fixed by these guards. A full conversion
requires the [explicit approval proposal](DECIMAL_MIGRATION_APPROVAL.md).
